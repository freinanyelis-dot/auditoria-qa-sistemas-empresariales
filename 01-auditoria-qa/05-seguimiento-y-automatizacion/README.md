## 4. Automatización con Power Automate

Power Automate se utiliza para enviar alertas automáticas por correo electrónico según las condiciones registradas en las listas de seguimiento.

| Condición | Acción automática |
|---|---|
| Un proceso se clasifica como posible desuso | Se envía una alerta con información del módulo, menú, proceso y último acceso registrado. |
| Un proceso obtiene resultado FAIL | Se envía una alerta con información del proceso, el hallazgo y la recomendación registrada. |
| Se registra un riesgo de nivel alto | Se envía una alerta para facilitar su revisión y atención. |
| Un caso de prueba obtiene resultado FAIL | Se envía una alerta para facilitar el seguimiento de la prueba. |
