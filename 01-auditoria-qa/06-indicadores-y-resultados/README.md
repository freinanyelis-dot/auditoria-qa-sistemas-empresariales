# Indicadores y resultados

Los datos de este documento son ficticios y se crearon solo con fines demostrativos. No corresponden a ningún sistema ni empresa real.

## 1. Objetivo

Visualizar el avance de la auditoría y sus resultados para facilitar el seguimiento y la toma de decisiones.

## 3. Cómo se leen los indicadores

- Un avance bajo indica que quedan procesos por revisar y ayuda a priorizar.
- Un porcentaje alto de FAIL señala procesos que requieren atención.
- Un porcentaje alto de N/A suele indicar limitaciones de acceso, no fallas del sistema.
- Muchos hallazgos documentales muestran que los manuales necesitan actualización.
